# Fixed extension from five to ten training seeds

This extension retains the original execution model, methods, hyperparameters, final-checkpoint rule, eight evaluation scenarios, 1,024 common paths per scenario and evaluation seed 90210 in `../experiments/PROTOCOL.md`. The scientific training and evaluation script is copied byte for byte from that package and uses the same isolated Python 3.6.6, NumPy 1.15.1 and PyTorch 0.4.1 runtime. Only `training_seeds` changes in the configuration.

The extension is declared after inspecting the initial five-seed result. It is not represented as an original ten-seed preregistration. Original seeds are 11, 23, 37, 53 and 71; additional seeds are 89, 107, 127, 149 and 173. Each added seed is run for all combinations of DDPG/TD3 and nominal/randomized training. All twenty additional runs will be completed and included without optional stopping, favorable-seed selection, changes in the training budget or hyperparameter tuning. Original evidence remains unchanged and is hash-checked against preserved copies.

The original primary contrast remains randomized minus nominal TD3, equally weighted over the seven nonnominal scenarios. The ten matched training-seed differences receive a Student t interval with nine degrees of freedom, using the 97.5-percentile critical value 2.2621571628540993. The interval is conditional on the fixed common Monte Carlo paths. Other comparisons remain descriptive. The extension reduces training-seed uncertainty without adding a matched adaptive controller or empirical-market calibration.

All freeze, training, evaluation and analysis timestamps record the actual execution time. `extension-plan.json` records the original input hashes and the fixed extension decision before additional training begins. Its sibling `frozen-protocol.json` hash-binds the extension configuration, this protocol, the unchanged scientific script and the original runtime manifest. Evaluation is regenerated under the same common path seed; extension verification must establish that the paths and every original policy result remain equal to their saved parent values.
